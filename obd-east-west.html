Live data endpoints

Open DockFlow / YMS / SSP in your browser, DevTools → Network, find the request that returns the data (filter by Fetch/XHR), and copy the full Request URL. Paste it below. The proxy routes it by host (dockflow.robotics.a2z.com → /api/dockflow; trans-logistics.amazon.com — YMS and SSP — → /api/yms). If the request is a POST/GraphQL, set method to POST and paste the request payload.
